# Project Documentation

## Overview
This directory is reserved for supporting documentation for the Olist Data Warehouse capstone project.

## Documentation Purpose
Project documentation is intended to explain:
- The data warehouse architecture and Medallion design.
- The ETL workflow and processing sequence.
- Data transformation and validation decisions.
- Database design and project implementation.
- Execution requirements and setup instructions.

## Main Documentation
The primary project documentation is maintained in the root `README.md`.

Additional technical documentation is available in:
- `ssis/README.md` - SSIS project structure and execution.
- `data/README.md` - Source dataset information.
- `sql/README.md` - SQL directory guide.
- `sql/bronze/README.md` - Bronze layer guide.
- `sql/silver/README.md` - Silver layer guide.
- `sql/gold/README.md` - Gold layer guide.
- `tests/README.md` - Testing and validation approach.
